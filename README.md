# E-commerse-web-application
My E-Commerce Web Application is an online shopping platform designed to make shopping easier and more convenient for users. Customers can register, log in, browse different products, search for products, add items to their shopping cart and place orders. The application also provides an admin panel to manage products, users and orders.
